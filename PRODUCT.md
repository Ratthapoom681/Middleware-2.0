# Product

## Register

product

## Users
Security engineers, analysts, and developers triaging vulnerabilities, syncing findings with Redmine, and managing local users.

## Product Purpose
DefectDojo Viewer acts as a secure, efficient middleware tool to pull findings from DefectDojo, create or verify corresponding Redmine tickets, and cache status updates locally.

## Brand Personality
* Clean
* Technical
* Developer-friendly
* Focused on dark theme visual aesthetics

## Anti-references
* Cluttered SaaS dashboards
* Overly flash/bloated UI animations
* Low-contrast, hard-to-read text on tinted dark backgrounds

## Design Principles
* **Functional Precision**: Information hierarchy is explicit and dense, allowing users to scan configuration fields and status actions instantly.
* **Trust & Clarity**: Every save, clear, or backup action provides clear, unambiguous status feedback.
* **Density Control**: Maintain a high-density, clean developer-friendly layout that doesn't waste space but remains easy to read.

## Accessibility & Inclusion
* High-contrast text on dark backgrounds (WCAG Level AA target of 4.5:1 ratio).
* Clean font sizing and line spacing.
